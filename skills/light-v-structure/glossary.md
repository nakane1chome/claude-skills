# Glossary

Terms used in this skill that may need clarification.

| Term | Definition |
|------|------------|
| ADR | Architecture Decision Record - a document capturing a significant architectural decision, its context, and consequences |
| Architectural quanta | Independently deployable units with high functional cohesion |
| Completed increment | A V-model increment strategy where multiple stages are completed atomically in one branch/PR |
| Pipelined increment | A V-model increment strategy (sashimi model) where stages overlap across working units |
| NFR | Non-Functional Requirement — a quality attribute constraint on the system (performance, scalability, security, etc.) rather than a specific behaviour |
| PoC | Proof of Concept |
| Quantization noise | In agent workflows, alignment jumps where the model "snaps" to the wrong abstraction boundary |
| Stochastic noise | In agent workflows, random variations in implementation decisions across runs |
| TDD | Test-Driven Development — writing tests before implementation; applicable on the right side of the V when test information is incomplete but the left-side counterpart exists |
| V-model | A systems development lifecycle with verification and validation built in, used here as a risk control framework rather than a prescriptive process |
